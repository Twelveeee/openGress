# Ingress 游戏物品大全

## 概述

Ingress 游戏中有多种物品，主要用于捕获门户、攻击敌方门户、建立连接和区域等核心游戏玩法。

## 核心物品

### 1. Resonators (谐振器)

| 等级 | 能量值 | 覆盖范围 | 描述 |
|------|--------|----------|------|
| L1   | 1,000  | 40m      | 入门级谐振器 |
| L2   | 1,500  | 42m      | 基础级谐振器 |
| L3   | 2,000  | 80m      | 进阶级谐振器 |
| L4   | 2,500  | 160m     | 中级谐振器 |
| L5   | 3,000  | 320m     | 高级谐振器 |
| L6   | 4,000  | 640m     | 专家级谐振器 |
| L7   | 5,000  | 1,280m   | 大师级谐振器 |
| L8   | 6,000  | 2,560m   | 顶级谐振器 |

- **用途**: 放置在门户上用于捕获门户
- **部署要求**: 最多8个谐振器/门户，通常采用不同等级混合部署以优化覆盖范围
- **衰减率**: 所有等级相同，每天损失 15% 的最大能量，约 6-7 天后归零

### 2. XMP Bursters (XMP 爆炸器)

| 等级 | 描述 | 最大伤害 | 爆炸半径 |
|------|------|---------|---------|
| L1 | 入门级 XMP 爆炸器 | 150 | 35m |
| L2 | 基础级 XMP 爆炸器 | 300 | 42m |
| L3 | 进阶级 XMP 爆炸器 | 500 | 48m |
| L4 | 中级 XMP 爆炸器 | 800 | 55m |
| L5 | 高级 XMP 爆炸器 | 1200 | 62m |
| L6 | 专家级 XMP 爆炸器 | 1700 | 72m |
| L7 | 大师级 XMP 爆炸器 | 2200 | 85m |
| L8 | 顶级 XMP 爆炸器 | 3000 | 100m |

- **用途**: 区域性攻击武器，摧毁一定范围内的敌方谐振器
- **伤害公式**: 距离越近伤害越高，中心获得最大伤害
- **伤害计算**: `实际伤害 = 最大伤害 × (1 - 距离/半径)`，距离超过半径为 0
- **使用**: 距离门户越近，伤害越高

### 3. Ultra Strikes (超能打击)

| 等级 | 最大伤害 | 爆炸半径 | 描述 |
|------|---------|---------|------|
| L1   | 300     | ~25m    | 入门级超能打击 |
| L2   | 500     | ~28m    | 基础级超能打击 |
| L3   | 700     | ~32m    | 进阶级超能打击 |
| L4   | 900     | ~35m    | 中级超能打击 |
| L5   | 1,200   | ~38m    | 高级超能打击 |
| L6   | 1,500   | ~40m    | 专家级超能打击 |
| L7   | 2,000   | ~42m    | 大师级超能打击 |
| L8   | 2,500   | ~45m    | 顶级超能打击 |

- **用途**: 精准攻击特定谐振器，减少对周围的影响
- **特点**: 爆炸半径小，伤害集中，比 XMP 伤害更高
- **适用场景**: 针对特定目标的精确打击、破坏模组

#### Ultra Strike vs XMP 对比

| 特性 | Ultra Strike | XMP Burster |
|------|--------------|-------------|
| 爆炸半径 | 小 (~25-45m) | 大 (35-100m) |
| 伤害 | 高，针对单个目标 | 范围伤害，随距离衰减 |
| 主要用途 | 精准削弱谐振器、破坏模组 | 大范围攻击多个谐振器 |

### 4. Portal Keys (门户钥匙)

| 稀有度 | 描述 | 作用 |
|--------|------|------|
| 普通、稀有、极稀有 | 特定门户的钥匙 | 用于连接门户和充电 |

- **用途**:
  - 建立连接 (Links) 需要两端门户的钥匙
  - 创建区域 (Fields) 需要三个门户的钥匙
  - 给门户充能
- **获取**: 入侵 (Hack) 门户获得
- **最大持有量**: 每个门户最多持有 2 把钥匙

### 5. Power Cubes (能量块)

| 等级 | 恢复 XM 量 | 描述 |
|------|-----------|------|
| L1   | 1,000 XM  | 入门级能量块 |
| L2   | 2,500 XM  | 基础级能量块 |
| L3   | 5,000 XM  | 进阶级能量块 |
| L4   | 10,000 XM | 中级能量块 |
| L5   | 20,000 XM | 高级能量块 |
| L6   | 40,000 XM | 专家级能量块 |
| L7   | 70,000 XM | 大师级能量块 |
| L8   | 100,000 XM| 顶级能量块 |

- **用途**: 快速恢复玩家的 XM 能量
- **充电**: 可以回收能量块为门户充能
- **合成**: 可作为材料合成更高等级能量块（如启用合成系统）

### 6. Mods (强化模组)

#### Portal Shields (门户护盾)

| 稀有度 | 伤害减免 |
|--------|----------|
| Common | 10%      |
| Rare   | 15%      |
| Very Rare | 20%   |
| Aegis Shield | 30% | 特殊 Very Rare |

- **叠加规则**: 最多 4 个模组，同一类型最多 2 个
- **Aegis Shield 特殊**: 每门户最多只能部署 2 个，最高可达 60% 伤害减免

#### Link Amps (连接增幅器)

Link Amp 模组对基础连接距离进行倍率放大：

| 配置 | 倍率 (Amplification) |
|------|----------------------|
| 1 × Rare    | 2 x                  |
| 2 × Rare    | 2.5 x                |
| 3 × Rare    | 2.75 x               |
| 4 × Rare    | 3 x                  |
| 1 × Very Rare | 7 x                  |
| 2 × Very Rare | 8.75 x               |
| 3 × Very Rare | 9.625 x              |
| 4 × Very Rare | 10.5 x              |
| 1 × SoftBank Ultra Link | 5 x                 |
| 2 × SoftBank Ultra Link | 6.25 x              |
| 3 × SoftBank Ultra Link | 6.875 x             |
| 4 × SoftBank Ultra Link | 7.5 x               |

**注意**:
- **SoftBank Ultra Link** (日本限定特殊模组): 提供 5-7.5 x 倍率
- Link Amp 不影响连接数量上限 (仍为 8 条)
- 最多可部署 4 个 Link Amp

#### Force Amps (力场增幅器)

| 稀有度 | 伤害加成 |
|--------|----------|
| Common | 20%      |
| Rare   | 25%      |
| Very Rare | 30%   |

- **效果**: 增加门户对入侵者的反击伤害

#### Turrets (炮塔)

| 稀有度 | 命中率提升 | 暴击率 | 暴击伤害倍率 |
|--------|------------|--------|--------------|
| Common | +10%       | 5%     | 1.2x         |
| Rare   | +20%       | 10%    | 1.4x         |
| Very Rare | +30%   | 15%    | 1.6x         |

- **效果**: 提高门户反击命中率和暴击伤害

#### Heat Sinks (冷却器)

| 稀有度 | 冷却时间减少 |
|--------|-------------|
| Common | 20%         |
| Rare   | 50%         |
| Very Rare | 70%      |

- **效果**: 减少入侵冷却时间

#### Multi-Hacks (多重入侵)

| 稀有度 | 额外破解次数 |
|--------|--------------|
| Common | +4 次        |
| Rare   | +6 次        |
| Very Rare | +8 次    |

- **Ito En Multi-Hack**: 特殊版本，冷却更快
- **效果**: 增加门户冷却前的可破解次数（基础为 4 次，最多可达 12 次）

## 特殊物品

### 1. Virus Weapons (病毒武器)

| 物品 | 阵营转换 | 作用 |
|------|----------|------|
| ADA Refactor (ADA 重构器) | 蓝色 | 将敌方门户转换为己方阵营 |
| Jarvis Virus (贾维斯病毒) | 绿色 | 将敌方门户转换为己方阵营 |

- **用途**: 将敌方门户立即转换为己方控制
- **限制**: 每个门户只能被转换一次
- **冷却时间**: 转换后的门户有一段保护期

### 2. Kinetic Capsules (动能胶囊)

- **用途**: 合成物品
- **操作**: 放入原料和所需时间，等待合成完成
- **常见合成**: 从低等级物品合成高等级物品

## 物品稀有度

1. **Common (普通)**: 白色图标，基础效果
2. **Rare (稀有)**: 蓝色图标，强化效果
3. **Very Rare (极稀有)**: 紫色图标，最高效果

## 物品获取方式

| 方式 | 描述 |
|------|------|
| Hack (入侵) | 主要获取方式，入侵门户获得随机物品 |
| Recycle (回收) | 回收不需要的物品换取 XM |

## 物品管理与策略

### 入侵优化
- 装备 **Heat Sinks** 和 **Multi-Hacks** 以最大化入侵次数
- 使用高等级 Multi-Hacks 可以更频繁地入侵

### 攻击策略
- **XMP Bursters**: 适合大范围清理门户
- **Ultra Strikes**: 适合精确打击高价值目标
- 注意 XM 能量管理，合理使用 Power Cubes

### 防御策略
- 使用 **Shields** 保护门户
- 部署 **Turrets** 和 **Force Amps** 增加防御反击
- 使用高等级谐振器提高门户能量储备

### 连接与区域
- 每个门户需要 **Portal Keys** 才能建立连接
- 注意连接数量限制和距离限制
- 使用 **Link Amps** 扩展连接能力

---

*注: 本文基于 Ingress Prime 游戏机制整理，具体数值可能随游戏更新而变化。*

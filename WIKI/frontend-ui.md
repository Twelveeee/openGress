## 通用 UI 组件

### 1. 玩家标记 (Player Marker)

```
<PlayerMarker
├── 头像/头像框
│   └── 阵营颜色边框
└── 方向指示箭头
```

**交互**:
看就行了

---

### 2. Portal 标记 (Portal Marker)

```
<PortalMarker level={level} faction={faction}>
├── 基础形状：圆形
├── 等级颜色
    l0: 白色
│   ├── L1-L3: 绿色/蓝色
│   └── L4-L8: 深绿/深蓝
└── 能量环
    └── 根据能量百分比显示不同大小的环
```

**交互**:
- 鼠标悬停显示简要信息（名称、等级、能量）
- 点击打开门户详情页

---

### 3. 连接线 (Link Line)

```
<LinkLine from={[fromLat, fromLon]} to={[toLat, toLon]} faction={faction}>
├── 线条样式
│   ├── Resistance: 蓝色，2px 粗
│   ├── Enlightened: 绿色，2px 粗
│   └── Red: 红色，2px 粗
└── 动画效果
    └── 链接创建时从起点流向终点的动画
```
link 不允许相交

---

### 4. 控制区域 (Control Field)

```
<ControlField portals={[p1, p2, p3]} faction={faction}>
├── 填充颜色
│   ├── Resistance: 蓝色透明度 0.2
│   ├── Enlightened: 绿色透明度 0.2
│   └── Red: 红色透明度 0.2
└── 边框
    └── 部分边框，显示所属阵营颜色
```
多个Field 叠加时，填充颜色可以叠加。

### 6. 门户谐振器显示 (Resonator Display)

```
<ResonatorsDisplay>
├── 8 个位置指示器
│   ├── 按 N/NE/E/SE/SW/SW/NW 方向排列，放置Resonator的时候可以选择放在那一个slot。根据 player到 portal的距离，每个Resonator 到portal的距离为放置时player到portal的距离

**视觉反馈**:
- 等级越高，颜色越深
- 能量低时显示红色警告
- 归属己方阵营显示自己阵营图标

### 9. 等级进度条 (Level Progress)

```

## 动画效果

### 玩家移动

```
点击地图 → 玩家平滑移动到目标位置
动画时长：取决于距离（固定速度）
```

### 连接创建

```
连接两端 Portal → 从起点到终点的光流动画
动画时长：1 秒
颜色：对应阵营颜色

如果 link 形成了 field, 则需要同步生成 field
```

### Portal 被捕获

```
Portal 阵营改变 → 闪烁动画后变为新阵营颜色
闪烁次数：1 次
```

## 无障碍设计

### 语义化 HTML

- 所有按钮使用 `<button>` 标签
- 图标使用 `<img>` 带 `alt` 文本
- 输入框使用 `placeholder` 属性
- 重要信息使用 `aria-label` 标记

### 对比度

- 前景色: #F0F2F4 (浅灰)
- 背景色: #FFFFFF (纯白)
- 文字颜色: #1A1A1A (深灰)
- 边框颜色: #D1D5DB (中灰)
- 可见文字: 4.5 (AAA)
- 禁用元素: 3 (AAA)

## 设计原则

1. **简洁优先** - 避免过多装饰元素
2. **视觉层级** - 使用阴影、边框区分元素层级
3. **反馈明确** - 每个操作都有视觉和听觉反馈
4. **性能至上** - 优化大量标记时的渲染性能
5. **阵营清晰** - 使用颜色明确区分三个阵营

# Ingress 玩家属性

## 概述

在 Ingress 中，玩家通过获得 Access Points (AP) 来升级。随着等级提升，玩家的 XM 容量和物品容量上限都会增加。

### 容量增长说明

- **L1-L8**: 每升一级增加 50 个槽位
- **L9-L16**: 每升一级增加 100 个槽位
- **L16**: 达到最大值 (2,000 General + 2,000 Key = 4,000 总容量)

## 物品容量系统

### 分离式计数

物品容量分为两个独立的计数系统：

| 槽位类型 | 用途 | 物品 |
|----------|------|------|
| **General** | 存放所有物品 | XMP, Resonator, Ultra Strike, Power Cube, Mod, Key |
| **Key Only** | 仅存放钥匙 | Portal Key |

### 注意事项

- **钥匙占用规则**: 钥匙只占用一种槽位；优先占用 Key Only 槽位
- **钥匙槽优先**: 当 Key Only 槽位已满时，新获取的钥匙会占用 General 槽位
- **容量限制**: 槽位满后无法获取新物品，必须先回收或使用物品

## XM 系统

### XM 作为生命值

- XM 是玩家的"血量"
- 所有操作都需要消耗 XM：
  - 攻击 (使用 XMP 或 Ultra Strike)
  - 部署谐振器
  - 安装模组
- XM 耗尽时：
  - **无法操作**: 无法攻击、部署、安装模组
  - **仍然可以移动**: 玩家角色仍可移动
  - **仍然可以 Hack**: 可以获取物品

### XM 恢复方式

| 方式 | 说明 |
|------|------|
| **自然恢复** | 随时间缓慢恢复 |
| **Power Cubes** | 使用能量块快速恢复 XM |
| **Hack** | 入侵门户有概率获得 XM |
| **Recycle** | 回收物品获得少量 XM |

## 等级限制

### 物品使用限制

- **规则**: X 级玩家最高只能使用 X 级的物品
- **向下兼容**: 高等级玩家可以使用低等级物品
- **向上限制**: 低等级玩家无法使用高等级物品

**示例**:
- L5 玩家: 可以使用 L1-L5 的物品，不能使用 L6-L8 的物品
- L8 玩家: 可以使用所有等级的物品 (L1-L8)

# Ingress Portal (门户) 详情

## 概述

Portal (门户) 是 Ingress 游戏中的核心游戏对象，现实世界中的地点、地标、艺术装置等都可以成为门户。玩家通过部署谐振器来捕获门户，建立连接和创建控制区域。

## Portal 属性

### 基本属性

| 属性 | 描述 |
|------|------|
| **Portal Level (门户等级)** | L1-L8，由部署的谐振器等级决定 |
| **Portal Energy (能量)** | 门户的总能量，所有谐振器能量之和 |
| **Resonators (谐振器)** | 最多8个，每个提供能量和覆盖范围 |
| **Mods (模组)** | 最多4个，强化门户的防御和功能 |
| **Owner (所有者)** | 捕获门户的玩家 |
| **Faction (阵营)** | Enlightened (绿色) 或 Resistance (蓝色) |

### Portal 等级计算

门户等级由部署的8个谐振器的平均等级决定：

```
Portal Level = (R1 + R2 + R3 + R4 + R5 + R6 + R7 + R8) / 8
```

| 谐振器配置 | 门户等级 |
|-----------|---------|
| 8 × L8 | L8 |
| 4 × L8 + 4 × L7 | L7.5 → L8 |
| 8 × L7 | L7 |
| ... | ... |
| 8 × L1 | L1 |

## Portal 状态

### 状态类型

| 状态 | 描述 | 行为 |
|------|------|------|
| **Neutral (中立)** | 无谐振器 | 任何玩家都可以捕获 |
| **Captured (已捕获)** | 有谐振器 | 属于特定阵营 |
| **Decayed (衰减)** | 能量减少 | 需要充能 |

### Portal 衰减

- 谐振器每 24 小时衰减 15% 的能量
- 如果所有谐振器能量归零，门户变回中立状态
- 需要玩家主动充能维持门户状态

## Portal 功能

### 捕获 Portal

1. 找到一个中立门户或摧毁敌方门户
2. 部署第 1 个谐振器 = 捕获门户（获得 500 AP）
3. 部署剩余谐振器以最大化门户能量和等级

### 升级 Portal

- 用更高等级的谐振器替换低等级谐振器
- 获得每次升级 65 AP
- 提高门户总能量和等级

### 充能 Portal

- 选择门户并点击充能按钮
- 消耗玩家 XM 为门户的谐振器补充能量
- 不获得 AP，但可维持门户状态

### 链接 Portal (Link)

- 需要两个门户的 Portal Key
- 连接数量和距离有限制
- Link Amp 模组可增加连接距离
- 获得 313 AP

#### 连接数量限制

| 类型 | 限制 |
|------|------|
| **Outgoing Links** | 每门户最多 8 条 |
| **Incoming Links** | 不限 |

#### 连接距离限制

连接距离由门户上**部署的谐振器配置**决定，而不是简单的门户等级：

##### 单玩家部署配置

| 等级 | 部署的谐振器配置（8 个） | Link Range |
|------|-------------------------|-----------|
| L1   | L1 L1 L1 L1 L1 L1 L1 L1 | 160 m |
| L2   | L2 L2 L2 L2 L1 L1 L1 L1 | 810 m |
| L3   | L3 L3 L3 L3 L2 L2 L2 L2 | 6.25 km |
| L4   | L4 L4 L4 L4 L3 L3 L3 L3 | 24.0 km |
| L5   | L5 L5 L4 L4 L4 L3 L3 L3 | 40.9 km |
| L6   | L6 L6 L5 L5 L4 L4 L4 L4 | 81.4 km |
| L7   | L7 L6 L6 L5 L5 L4 L4 L4 | 110.3 km |
| L8   | L8 L7 L6 L6 L5 L5 L4 L4 | 160.1 km |

##### 多玩家协作部署配置

当多名玩家在同一门户部署时，取每个位置的最高等级谐振器：

| 参与玩家 | 谐振器配置（8 个） | Link Range |
|----------|---------------------|-----------|
| 2 × L8   | L8 L8 L7 L7 L6 L6 L6 L6 | 332.1 km |
| 3 × L8   | L8 L8 L8 L7 L7 L7 L6 L6 | 412.3 km |
| 4 × L8   | L8 L8 L8 L8 L7 L7 L7 L7 | 506.2 km |
| 5 × L8   | L8 L8 L8 L8 L8 L7 L7 L7 | 540.8 km |

**说明**: 多名玩家在同一门户上部署时，每个位置的谐振器取最高等级，这可以大幅增加连接距离。

#### Link Amp 倍率加成

Link Amp 模组对基础连接距离进行倍率放大：

| Link Amp 配置 | 倍率 (Amplification) |
|--------------|----------------------|
| 0 个         | 1 x                  |
| 1 × Rare    | 2 x                  |
| 2 × Rare    | 2.5 x                |
| 3 × Rare    | 2.75 x               |
| 4 × Rare    | 3 x                  |
| 1 × Very Rare | 7 x                  |
| 2 × Very Rare | 8.75 x               |
| 3 × Very Rare | 9.625 x              |
| 4 × Very Rare | 10.5 x              |
| 1 × SoftBank Ultra Link | 5 x                 |
| 2 × SoftBank Ultra Link | 6.25 x              |
| 3 × SoftBank Ultra Link | 6.875 x             |
| 4 × SoftBank Ultra Link | 7.5 x               |

#### 计算示例

**示例 1**: 单玩家 L5 门户 + 1 × Very Rare Link Amp
- 基础距离: 40.9 km
- 倍率: 7 x
- 最终距离: 40.9 × 7 = **286.3 km**

**示例 2**: 4 × L8 玩家协作 + 4 × Very Rare Link Amp
- 基础距离: 506.2 km
- 倍率: 10.5 x
- 最终距离: 506.2 × 10.5 = **5,315.1 km**

### 创建控制区域 (Control Field)

- 用 3 个或更多连接的门户创建三角形区域
- 大型区域控制大量 Mind Units (MU)
- 获得大量 AP (1250 AP)
- 是游戏获胜的核心机制

## Portal 防御

### 防御策略

| 策略 | 方法 |
|------|------|
| **安装护盾** | Common/Rare/Very Rare Shields 减少攻击伤害 |
| **部署反击** | Turret + Force Amp 让门户自动攻击敌人 |
| **提高能量** | 高等级谐振器提高总能量，更难摧毁 |
| **优化位置** | 远离敌方活动区域的门户更安全 |
